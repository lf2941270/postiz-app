# 小红书集成指南

## 概述

小红书集成采用半自动化发布模式，因为小红书目前没有提供官方的内容发布 API。系统会为您准备好优化的内容和图片，然后提供详细的发布指导，您需要在小红书 APP 中完成最后的发布步骤。

## 功能特性

### ✨ 内容优化

- **智能格式化**: 自动添加小红书风格的 emoji 和标签
- **结构优化**: 改善内容的可读性和吸引力
- **标题生成**: 生成符合小红书风格的吸引人标题
- **互动引导**: 自动添加互动元素提高参与度

### 🖼️ 图片处理

- **尺寸优化**: 自动调整图片尺寸适配小红书要求
- **格式转换**: 确保图片格式兼容性
- **质量压缩**: 在保持质量的前提下减小文件大小
- **数量限制**: 自动处理最多 9 张图片的限制

### 📋 发布指导

- **分步指导**: 详细的 6 步发布流程
- **内容复制**: 一键复制优化后的内容
- **时间建议**: 基于用户活跃度的最佳发布时间
- **设置提醒**: 隐私、位置、话题等设置提醒

## 使用方法

### 1. 添加小红书账号

1. 在 Postiz 中点击"添加平台"
2. 选择"小红书"
3. 系统会自动配置为手动发布模式

### 2. 创建内容

1. 编写您的内容
2. 上传图片（建议 1:1 或 3:4 比例）
3. 配置小红书特定设置：
   - **话题标签**: 最多 5 个相关话题
   - **位置信息**: 可选的地理位置
   - **隐私设置**: 公开/仅好友/仅自己
   - **商业标记**: 如果是广告内容请勾选

### 3. 发布内容

1. 点击"发布"按钮
2. 系统会生成发布指导
3. 按照指导在小红书 APP 中完成发布
4. 发布完成后可标记为"已发布"

## 配置选项

### 话题标签 (topics)

```typescript
topics: ['生活方式', '美妆护肤', '旅行攻略'];
```

- 最多 5 个标签
- 系统会自动格式化为 `#标签#` 格式

### 隐私设置 (privacy)

```typescript
privacy: 'public' | 'friends' | 'private';
```

- `public`: 公开可见
- `friends`: 仅好友可见
- `private`: 仅自己可见

### 位置信息 (location)

```typescript
location: '北京·朝阳区';
```

- 可选的地理位置信息
- 会在内容末尾添加 📍 图标

### 商业内容 (isCommercial)

```typescript
isCommercial: true;
```

- 标记为商业内容时会添加【广告】标识
- 确保符合平台规范

## 最佳实践

### 📝 内容创作

1. **标题要吸引人**: 使用数字、疑问句、感叹号
2. **内容要有价值**: 提供实用信息或有趣观点
3. **长度适中**: 建议 20-1000 字符
4. **结构清晰**: 使用换行和 emoji 增加可读性

### 🖼️ 图片选择

1. **第一张最重要**: 决定用户是否点击
2. **保持一致性**: 风格统一的图片效果更好
3. **高质量**: 清晰、美观的图片更受欢迎
4. **比例合适**: 1:1 正方形或 3:4 竖版效果最佳

### ⏰ 发布时间

- **工作日**: 7:00-9:00, 12:00-14:00, 19:00-22:00
- **周末**: 10:00-12:00, 14:00-16:00, 19:00-22:00
- 系统会根据当前时间提供个性化建议

### 🏷️ 话题标签

1. **相关性**: 选择与内容高度相关的标签
2. **热度**: 适当使用热门话题增加曝光
3. **数量**: 建议 3-5 个，不要过多
4. **原创**: 可以创建独特的品牌标签

## 技术实现

### 架构设计

```
用户输入 → 内容处理 → 图片优化 → 发布指导 → 手动发布
```

### 核心组件

- **XiaohongshuProvider**: 主要的集成逻辑
- **XiaohongshuDto**: 配置验证和类型定义
- **PublishGuide**: 发布指导界面组件
- **ContentProcessor**: 内容格式化和优化

### 扩展性

系统设计支持未来小红书 API 的集成：

- 保留了标准的 Provider 接口
- 可以轻松切换到自动发布模式
- 支持添加新的功能特性

## 故障排除

### 常见问题

**Q: 为什么不能自动发布？**
A: 小红书目前没有提供官方的内容发布 API，只能通过手动方式发布。

**Q: 图片处理失败怎么办？**
A: 检查图片格式和大小，建议使用 JPG/PNG 格式，单张图片小于 20MB。

**Q: 内容格式化不正确？**
A: 检查内容长度和特殊字符，系统会自动优化但可能需要手动调整。

**Q: 话题标签没有生效？**
A: 确保标签相关性和格式正确，小红书可能对某些标签有限制。
